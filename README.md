#Cybersecurity Internship | Endpoint Protection, Monitoring & Threat Investigation

About the Project

This repository documents a hands-on cybersecurity internship project involving endpoint security implementation, system activity monitoring, threat investigation, and security event analysis.

The project combines Windows and Linux environments with different security tools to explore endpoint visibility, file integrity, forensic investigation, malware intelligence, and automated threat detection.

The primary focus was to gain practical experience with security tools and understand how different monitoring and investigation techniques work together in a real-world security workflow.

Technologies & Security Tools

- Windows 10 and Ubuntu Linux
- Sysmon
- Rustinel 1.0.2
- ETW (Event Tracing for Windows)
- PowerShell
- Linux Command Line
- SHA-256
- MalwareBazaar
- Sigma-style Detection Logic
- JSON Alert Records

Work Performed

1. Windows Endpoint Monitoring

- Set up the Windows endpoint monitoring environment.
- Installed and configured Microsoft Sysmon.
- Verified service operation and event collection.
- Investigated file-related system activity.
- Observed Event ID 11 during file creation testing.

2. File Integrity & Hash Analysis

- Created test files for security experiments.
- Used SHA-256 to generate file fingerprints.
- Practiced file integrity verification.
- Organized hash-related evidence and monitoring records.

3. ETW-Based Threat Detection

Using Rustinel:

- Downloaded and extracted the Windows x86_64 release.
- Initialized ETW tracing successfully.
- Monitored Windows process execution.
- Executed controlled process-testing commands.
- Tested the "whoami.exe /all" detection scenario.
- Verified a low-severity alert generated by the detection rule.
- Preserved the resulting JSON alert evidence.

4. Malware Intelligence & Investigation

Using MalwareBazaar:

- Explored malware intelligence resources.
- Studied malware hashes and indicators of compromise.
- Investigated how threat intelligence can support endpoint security.

5. Detection & Security Evidence

- Tested process execution detection.
- Reviewed detection rule matches.
- Examined alert severity.
- Worked with structured JSON security records.
- Organized investigation evidence and reports.
